Как самой допилить прогноз (книга Рашки, scikit-learn)

1. Признаки
   Править `_features()` в `forecast.py`: лаги, скользящее среднее,
   «месяц сдачи сессии/праздников», доля ЮЛ и т.д.

2. Своя модель на NumPy
   `fit_predict_numpy()` сейчас — обычный МНК.
   Идеи из Рашки без sklearn:
   - Ridge: w = (X^T X + λI)^(-1) X^T y
   - полином: добавить t^2 в признаки
   - нормализация столбцов X (zero-mean / unit-var)

3. Sklearn, если очень хочется лес
   pip install scikit-learn
   FORECAST_BACKEND=sklearn ./run.sh
   Тогда вызывается `fit_predict_sklearn()`.
   На 12–24 точках лес почти не лучше линейной модели с сезонностью,
   зато пакет весит сотни МБ.

4. Метрика для главы «эксперимент»
   Посчитай MAE: для каждого известного месяца обучись без него
   и сравни прогноз с фактом. Это leave-one-out, кода мало, для курсача отлично.
